# Smart Inventory & Sales Management System

HTML + CSS + JavaScript web app. No installation needed.

## How to run
Open the folder in VS Code and double-click **index.html**
(or right-click -> Open with Live Server).

## Modules
- Dashboard: revenue, profit, sales count, stock value, low-stock alerts, top products, 7-day chart
- Inventory: add / edit / delete / search / restock products (cost + selling price)
- New Sale: billing cart, discount %, 5% GST, payment method, stock auto-reduces
- Sales History: all invoices, view / print invoice, export CSV
- Customers: manage customers, purchases and total spent
- Reports: sales by category (with profit) and by payment method

Data is stored in the browser (localStorage).
Files: index.html, style.css, script.js
